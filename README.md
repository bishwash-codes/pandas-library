# Pandas Learning

Learning pandas as step one toward a career in data science and AI/ML engineering. Every notebook here is practice code I wrote myself.

## Goal
Be able to load, clean, analyze and prepare real datasets with pandas, then use that skill for visualization and machine learning.

## Structure
- `notebooks/`: one notebook per topic, numbered in the order I learned them
- `data/`: small practice datasets
- `projects/`: end-to-end analyses on real datasets



## Setup
```
py -m pip install pandas ipykernel
```
Open any `.ipynb` file in VS Code and select the Python 3.14 kernel.
